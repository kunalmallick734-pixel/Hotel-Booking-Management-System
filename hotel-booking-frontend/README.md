# Roomzy Frontend — React 18 + Vite SPA

Modern, responsive hotel booking Single Page Application for **Roomzy** built with **React 18**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## 🚀 Features
- **Indian Checkout Experience**: MakeMyTrip / Goibibo style checkout with UPI QR, UPI ID, RuPay/Cards, and Net Banking.
- **Search & Filter**: Real-time multi-criteria filtering by star rating, hotel type, facilities, budget, and destination.
- **Role-based Dashboards**: Guest Bookings, Hotel Owner Property Manager, and Admin Analytics.
- **Brand Identity**: Styled with **Roomzy Deep Ruby & Wine Gradient**.

## 📦 Scripts
```powershell
npm run dev     # Start Vite dev server on http://localhost:5174
npm run build   # Production bundle build
npm run lint    # ESLint check
```
